Per-step resources. "Advanced Settings" gains a Per-step resources section: a sizing override per step (floor, intercept, slope, cap, CPU), which beats the global memory and CPU overrides for that step and does not re-run finished samples, and a "List the steps of this preset" button that plans the steps before any run.
